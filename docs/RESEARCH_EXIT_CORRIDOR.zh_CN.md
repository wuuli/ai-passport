# 8号出口：参考与原型决策

调研日期：2026-09-18。视觉方向已于 2026-09-19 纠正：《德军总部 3D》是技术参考，不是像素美术要求。网页目标是尽量贴近《8号出口》氛围的地下通道，具备细腻材质、光照、解剖结构和连续动画；玩法依旧围绕观察、怀疑和实体三键回头决策。这是受《8号出口》启发的原创原型与固件实现，不是商业专属资产或闭源实现的代码复刻。

## 哪些是设计解释，而非已核实的原作实现

公开说明未给出具体异常数量、生成权重、防重规则、首轮行为、随机种子、边界几何尺寸或失败处理。连续正确八次通关、错误归零来自前期讨论，属于原型规则。不可将固定的出现概率、必定正常的首轮或某些看起来逼真的具体异常标榜为已鉴定的原作复刻。

有效的设计假设是：**识别 → 比较 → 怀疑 → 走动确认 → 进入下一段看似相同的通道**。正常轮必须足够逼真；危险特效不能在每次异常轮直接剧透。游戏允许玩家停下细看，不设倒计时。

## 当前架构与交付事实

- **核心实现**：交付方案在 ESP32-C3 固件（`main/demo_corridor.c`）和 WebAssembly 网页端（`prototype/exit-corridor/firmware/corridor.wasm`）共用同一套 C 语言游戏规则引擎（`main/corridor_game.c`）和 2.5D 软件渲染器（`main/corridor_render.c`）。
- **画面与环境**：针对原生 240 × 320 竖屏设计。墙面采用浅灰纯色并保留纵深光照与踢脚线，横向连接通道墙面（`side >= 2`）暗一级以保证拐角明暗对比，无需程序化贴图查表或 PNG 图集。
- **角色渲染**：离线烘焙 2D 精灵包（`assets/images/exit-corridor/commuter-device.bin`，312,689 B），源自经 MIT 许可的 Rocketbox 便服通勤者（commit `0943055db6ec570bcef9f2c8b41c9e5467c808f9`，8 方向 × 16 步态 + 1 站姿，48×96 单元格）。C 渲染器按需仅将当前活跃帧解码到单帧缓冲（4,608 B 像素 + 576 B 遮罩）。详见[素材说明](../assets/images/exit-corridor/README.zh_CN.md)。
- **操作与导引**：唯一实体三键方案（上下键按下立即转向 45°、OK 短按在松开时走停；长按 1 秒退回标题／菜单）。自动行走沿 0.85 米圆弧平滑过弯并正对下段通道停步，支持 OK 暂停／继续及按键立即覆盖。正对侧墙时平滑对中附近标准物件位置（斜向可见物件扩展至 1.2 米），限速运行（<=1.2 米/秒），正常与异常场景锚点完全一致。
- **规则与异常**：八种原创异常（缺门、海报眼睛、倒挂海报、额外通风口、红灯、高大路人、停止凝视、路人缺席）。跨界按进入侧判断前行或折返。连续正确通过 8 次通关，走错归零；单纯转身不提交判断。通用规则置于入口左墙（$Z = -3.5$）实体告示牌；盲玩不剧透答案。
- **WebAssembly 预览**：入口为 [`prototype/exit-corridor.html`](../prototype/exit-corridor.html)，通过 `python3 tools/serve_corridor_web.py --port 8098` 监听回环地址。通过一致性门禁验证原生 C 与 Wasm 像素级一致。详见[网页同步说明](WEB_PREVIEW_EXIT_CORRIDOR.zh_CN.md)。

## 硬件约束与资源核算

| 硬件约束 | 交付实现事实 |
| --- | --- |
| ESP32-C3 无 PSRAM；8 MB Flash，3 MB 应用分区 | 全部游戏引擎、字模子集与角色素材均在应用 Flash 镜像（约 2.31 MB）内；两块 40 行显示 DMA 缓冲（共 38,400 B）位于内部 RAM。Flash 资产：路人包 305.36 KiB、RGB565 查表 64 KiB、Noto Sans SC 字模子集。纯色墙面占用 0 字节 Flash 查表。 |
| ST7789P3，240 × 320 竖屏 RGB565，SPI2 40 MHz | 全尺寸原生渲染。原生索引帧缓冲为 77,824 B（含 1,024 B ARGB8888 调色板）。 |
| 两个 240 × 40 RGB565 DMA 缓冲（共 38,400 B） | 采用两块 40 行双缓冲实现渲染与 SPI 传输重叠；通过按需串口行流式传输（`FAP_SCREENSHOT_V1`）替代原 40,800 B 常驻截图全帧缓冲提供内存空间。 |
| 内部堆工作内存 | 渲染器工作区在 64 位主机上占 13,264 B 分块分配（真机 32 位结构大小以运行时日志为准），含 576 B 1位透明遮罩。五行 RGB565 扫描输出及调色板占用 2,912 B 静态内存。历史运行时样本录得内部空闲堆保持 27,500～27,572 B（最低 23,060 B，最大连续块 14,848 B）。 |
| GPIO0 上的 ADC 三键分压 | 非阻塞 ADC 输入处理。方向键按下立即转向；OK 短按在松开时生效；长按 1 秒退出。 |
