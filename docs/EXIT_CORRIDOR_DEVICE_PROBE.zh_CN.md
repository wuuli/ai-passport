# 地下通道真机验证清单

游戏使用原生 240x320 渲染。早期独立验证页面和降档渲染方案已由 `main/demo_corridor.c` 取代。实测请见[设备记录](DEVICE_VALIDATION_EXIT_CORRIDOR.zh_CN.md)；下面的目标不代表已经达到的性能。

## 测量

- 预热五秒，分别记录至少 30 秒的行走、转向、拐角辅助和观察对中。计时期间不要截图。
- 现有 `corridor` 日志输出窗口提交帧数、平均渲染 CPU 时间、最后一帧地面/墙体/人物 CPU 时间、刷新时间、空闲/最低堆和最大连续块。提交帧率不是面板完成帧率；串口零字节不代表稳定。
- 每次记录固件和素材哈希、显示配置、场景和采样时长。不同场景的数据不能直接证明优化收益。
- 尚未测量：面板完成间隔 p50/p95/p99、超时帧比例，以及两个 40 行显示缓存下的并发 I2S/音频 DMA 压力。持续 20 FPS 是目标，不是发布保证。

## 实体检查

- 从 0 玩到 8；确认判断错误回到 0，第八次正确通过后出现完成画面。
- 检查前后拐角、两个进入方向、全部八种异常、轻柔对中、按键立即接管和走停。
- 在实体屏幕上观察纯色墙面运动和垂直墙面明暗差，不能只看串口截图。
- 重复进入、长按 OK 退出、再进入；回归掐秒挑战声音/计时，以及原有显示/音频页面。
- 保持 UP/DOWN 转向、短按 OK 走停；不需要新增 BSP 释放事件或第二套操作。

## 安装安全

USB 仅更新应用前，核对发布镜像和设备分区表，并保留已核实应用分区的回滚备份。不要无必要地读取或覆盖身份/NVS 数据。

应用从 `0x10000` 开始，必须小于 3 MB。保留 `0x356000` 的 `cardid`、`0x700000` 的永久 Recovery 和五秒 UP 启动钩子。构建成功或传输成功不代表正常游玩。
